# ABL Telegram Bot

Публичный Telegram-бот для мониторинга расписания матчей и цвета игровой формы в баскетбольной лиге ABL (https://ablforpeople.com).

## Как использовать в любой команде

1. Добавьте бота в чат вашей команды.
2. **Администратор группы** настраивает команду:
   ```text
   /set БК Путилково
   ```
   Привязка без дивизиона отслеживает команду и в квалификации, и в основном сезоне.
   Актуальный дивизион берётся из данных лиги для каждого матча. Старый формат `/set НазваниеКоманды | Дивизион` принимается для совместимости, но дивизион больше не ограничивает поиск.
   Например, у БК Путилково квалификация проходила в «Москвич», а основной сезон 2026/27 — в «BASE».
3. Бот подтвердит привязку. Теперь:
   - Как только лига назначит новый матч — бот автоматически пришлёт расписание, зал, цвет формы и голосование «Буду / Не буду / Под вопросом». Расписание проверяется раз в 5 минут.
   - Если опубликовано несколько новых матчей, каждый получит свой анонс и голосование.
   - Повторных напоминаний за сутки и перед началом игры нет. Если голосование не отправилось из-за сбоя, бот повторит его отправку без повторного анонса.
   - Любой игрок в чате может написать `/game` или `/schedule`, чтобы посмотреть актуальную информацию.

## Скаутинг ближайшего соперника

`/scout` (или `/скаут`) показывает статистику игроков ближайшего соперника команды, привязанной к чату. Например, для БК Путилково бот сам найдёт ближайшую игру с BOOMS и подготовит отчёт по BOOMS.

`/scout HDXSEVER` показывает статистику **самой HDXSEVER**, независимо от привязки чата. Название ищется в каталоге текущего сезона; при неоднозначном совпадении бот попросит уточнить его. Команда доступна всем участникам; отчёт отправляется только по запросу.

Отчёт оформлен короткими карточками для телефона: номера и имена игроков, очки, подборы, передачи, перехваты и блоки в среднем за матч, трёхочковые попадания/попытки и процент. Показаны до 8 игроков по средней результативности. У каждого игрока указано число матчей.

В конце — общий топ-5 по среднему коэффициенту полезности ABL. Для каждого лидера показаны очки, подборы, передачи и КП. Рейтинг учитывает всех игроков, в том числе не попавших в восемь основных карточек.

Неактивные записи без действующей заявки не попадают в карточки и топ-5. Состав сверяется с ABL; у действующих игроков сохраняется статистика прошлых этапов, даже если их прежняя заявка уже неактивна.

Статистика берётся по всем завершённым матчам сезона, включая квалификацию и основной этап. Для автоматического скаутинга используется сезон ближайшей игры, для указанной команды — текущий сезон лиги. Записи одного игрока с разных этапов объединяются: суммы показателей делятся на общее число его матчей. Данные других сезонов не добавляются.

В шапке указан средний доезд за сезон: общее число участий игроков в сыгранных матчах, делённое на число матчей команды по данным ABL. Размер сезонной заявки не используется. Если доезд определить не удалось, бот выводит «нет данных»; если выборка мала, предупреждение появляется перед топ-5.

## Обновление на сервере

В каталоге проекта выполните `git pull --ff-only`, затем перезапустите бот привычным способом (службу, если он запущен как служба; для ручного запуска — остановите текущий процесс и снова выполните `bash start.sh`).
Настройки и история отправок хранятся в `chats.json`: не удаляйте его при обновлении.
Сохранённые ранее фильтры дивизиона игнорируются автоматически — повторять `/set` после обновления не нужно.

Проверка без отправки сообщений в Telegram: `python3 -m unittest -q`.

## Безопасность
- Менять команду через `/set` могут **только создатели и администраторы конкретной группы**.
- Обычные участники группы не могут изменить или сбросить настройки.
- Настройки всех групп изолированы друг от друга в `chats.json`.
