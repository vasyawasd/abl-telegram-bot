# ABL Telegram Bot

Telegram-бот для мониторинга расписания матчей и цвета игровой формы в лиге ABL (https://ablforpeople.com).

## Возможности
- 🔔 **Авто-уведомления:** опрашивает API лиги раз в 10 минут и присылает сообщение в группу, как только назначен новый матч.
- 👕 **Цвет формы:** определяет цвет формы по позиции команды (слева — светлая, справа — чёрная).
- ⚙️ **Первичная настройка команд:** в личке с ботом можно настроить список команд и дивизионов, получив персональные команды активации.
- 🚀 **Простая активация в группах:** в группу достаточно отправить команду вида `/start_1` или `/start_путилково_москвич`.
- ⚡️ **По запросу:** игроки могут написать `/game`, `игра` или `форма`, чтобы получить актуальную информацию.

## Управление командами (в личке с ботом)

- `/teams` (или `/setup`) — показать список курируемых команд и команды для их добавления в группы.
- `/addteam Название Команды | Дивизион` — добавить новую команду (например: `/addteam БК Путилково | Перово`).
- `/delteam <номер>` — удалить команду из списка.

## Подключение к группам

1. Добавьте бота в чат группы нужной команды.
2. Отправьте в этот чат команду активации, сгенерированную ботом (например: `/start_1`).
3. Бот подтвердит привязку и начнет автоматический мониторинг!
